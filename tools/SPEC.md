## 0. What we are building

A portrait (9:16) 3D mobile endless-runner for Unity. A cute cartoon monkey, seen from behind,
runs on a long stone bridge through a vibrant fantasy jungle toward a glowing temple gate.
The player only steers left/right by dragging. Bananas (+1, missing one costs a life),
coconuts (hitting one costs a life) and a glowing 2X power-up (double score for 5 s) come
towards the player from the temple gate at the far end of the road.

Deliverable for the user: ONE file `BananaTime.unitypackage`. The user imports it into an empty
Unity project (Unity 6 "Universal 3D" template is the main target: URP + new Input System only;
it must ALSO work in a Built-in render pipeline project and with the legacy Input Manager, and
should compile on Unity 2022.3+). After import an editor script automatically builds all
materials, prefabs, the two scenes, build settings, and opens the MainMenu scene. The user
presses Play. Nothing else.

We cannot run the Unity editor here (no licence). We CAN compile C# against the real Unity
6000.0.84f1 assemblies (see §9), and we CAN render previews with Blender 4.5 (Cycles, CPU).

## 2. Coordinates, units, FBX export

- 1 unit = 1 metre. Unity: left-handed, Y up, +Z forward (down the road, away from camera).
- Blender mapping (see `tools/blender/btcommon.py`): Unity (x, y, z) == Blender (-x, -z, y).
  Characters face Blender -Y ⇒ Unity +Z. Use `bt.u2b()`.
- ALL FBX files are exported with `bt.export_fbx()` (FBX_SCALE_ALL, -Z forward, Y up, no leaf
  bones, `colors_type='SRGB'`, `path_mode='STRIP'`, textures NOT embedded).
- The Unity builder imports every model with: `globalScale=1, useFileScale=true,
  bakeAxisConversion=true`, no cameras/lights. The builder additionally sanity-checks the
  instantiated bounds against the expected sizes below and auto-fixes a 100x scale or a
  90°/180° orientation error, logging a warning.
- EVERY exported mesh must have a vertex colour layer named `Col` (use `bt.ensure_color_attribute`).
  RGB = colour/AO multiplier (white = no change). **Alpha = wind-sway weight** (0 = rigid, 1 = fully
  swaying). Meshes that must not sway: alpha 1 is fine as long as their material has `wind: 0`.
- Every mesh must have UVs (UVMap) even if untextured. Keep normals smooth where appropriate
  (shade smooth / auto smooth). Apply all transforms/modifiers before export. No n-gons issues:
  triangulate on export is fine.
- Material slot names in Blender become Unity material names. They MUST start with `BT_` and
  have an entry in the owner's `Materials_*.json`. Names must be unique across the project.
- Poly budgets (triangles): monkey ≤ 20k; each item ≤ 3k; each env segment ≤ 25k; backdrop ≤ 120k.
- Textures: PNG, power-of-two, ≤ 1024 px (sky/clouds may be 2048x1024). sRGB colour.

## 4. Shaders (owner: shaders) — must work in URP AND Built-in

Plain `CGPROGRAM` vertex/fragment shaders, `#include "UnityCG.cginc"` only, no `#pragma surface`,
no URP includes, no multi_compile_fwdbase. Lighting/fog are computed from MATERIAL properties (not
Unity lights) so both pipelines look identical. Target `#pragma target 3.0`. Put shared code in a
`CGINCLUDE` block. Structure every shader as TWO SubShaders:
1. `Tags { "RenderPipeline"="UniversalPipeline" ... }` — main pass `Tags { "LightMode"="UniversalForwardOnly" }`
   (works in URP Forward, Forward+ and Deferred), plus for opaque/clip shaders (Stylized) AND the Sky:
   a `DepthOnly` pass (`LightMode`="DepthOnly", `ZWrite On ColorMask R`), and two identical depth-normals
   passes (`LightMode`="DepthNormals" and `LightMode`="DepthNormalsOnly", output `float4(normalize(worldNormal),0)`),
   each replicating the SAME vertex displacement (wind) and alpha clip as the main pass, so URP
   depth priming / SSAO can never make our objects vanish.
2. A fallback SubShader with no RenderPipeline tag for the Built-in pipeline: the main pass with NO
   `LightMode` tag (plus nothing else required).
Verify: check tag lists against the URP source in
`/opt/unity/Editor/Data/Resources/PackageManager/BuiltInPackages/com.unity.render-pipelines.universal/`.
Vertex colours are sRGB: linearise with `GammaToLinearSpace` when `!IsGammaSpace()`.
Fog: `f = saturate((dist - _FogStart)/(_FogEnd - _FogStart)) * _FogMax * _FogAmount`, dist = distance
from `_WorldSpaceCameraPos`; `rgb = lerp(rgb, _FogColor.rgb, f)`. (Additive: `rgb *= 1 - f`.)
Wind: `worldPos.xz += sin(_Time.y*1.7 + worldPos.x*0.35 + worldPos.z*0.27) * _Wind * vcol.a`
(+ a second smaller frequency; y slightly), applied in object→world before projection.

### `BananaTime/Stylized` (opaque or alpha-clip, lit)
Properties (exact names): `_MainTex` (2D "white"), `_Color` (Color 1,1,1,1), `_VertexColorStrength`
(Range 0-1 = 1), `_Cutoff` (Range 0-1 = 0; 0 disables clip), `_Cull` ([Enum(UnityEngine.Rendering.CullMode)] = 2),
`_BumpMap` (2D "bump"), `_BumpScale` (Range 0-2 = 0; 0 = ignore), `_Unlit` (Range 0-1 = 0),
`_SunDir` (Vector -0.45,0.8,-0.4,0), `_SunColor` (Color 1,0.93,0.8,1), `_SunIntensity` (Float 1.15),
`_SkyAmbient` (Color 0.56,0.70,0.86,1), `_GroundAmbient` (Color 0.42,0.38,0.30,1),
`_AmbientIntensity` (Float 0.8), `_Wrap` (Range 0-1 = 0.35), `_Specular` (Color 1,1,1,0; A = strength),
`_Gloss` (Range 1-256 = 32), `_RimColor` (Color 1,0.9,0.7,0; A = strength), `_RimPower` (Range 0.5-8 = 3),
`_EmissionColor` (Color 0,0,0,1), `_EmissionMap` (2D "white"), `_EmissionIntensity` (Float 1),
`_Scroll` (Vector 0,0,0,0 uv/s), `_Wind` (Float 0), `_FogColor` (Color 0.78,0.86,0.92,1),
`_FogStart` (Float 25), `_FogEnd` (Float 230), `_FogMax` (Range 0-1 = 0.85), `_FogAmount` (Range 0-1 = 1).
Lighting: `albedo = tex*_Color*lerp(1,vcol.rgb,_VertexColorStrength)`;
`ndl = saturate((dot(N,L)+_Wrap)/(1+_Wrap))`; `amb = lerp(_GroundAmbient,_SkyAmbient, N.y*0.5+0.5)*_AmbientIntensity`;
`lit = albedo*(amb + _SunColor*_SunIntensity*ndl) + spec(blinn, _Gloss)*_Specular.rgb*_Specular.a*ndl`
`+ rim(pow(1-saturate(dot(N,V)),_RimPower))*_RimColor.rgb*_RimColor.a`;
`rgb = lerp(lit, albedo, _Unlit) + emission`; then fog. Queue Geometry, or AlphaTest(2450) when the
builder enables clipping (builder sets `renderQueue`). Double-sided (Cull Off) must flip the
normal for back faces (`VFACE`).
### `BananaTime/Transparent` (alpha blended, unlit)
`_MainTex`, `_Color`, `_VertexColorStrength`, `_Scroll`, `_DetailTex` (2D "white"), `_DetailScroll`,
`_Intensity` (Float 1), `_Cull` (= 0), `_OffsetFactor` (Float 0), `_OffsetUnits` (Float 0), fog props as above.
`rgba = tex(uv+_Scroll*t) * detail(uv2 or uv, +_DetailScroll*t) * _Color * vcol`; rgb *= _Intensity.
Blend SrcAlpha OneMinusSrcAlpha, ZWrite Off, Queue Transparent. Used for waterfalls, mist, clouds, blob shadows (vcol applies to particles too).
### `BananaTime/Additive`
`_MainTex`, `_Color`, `_Intensity` (Float 1), `_Scroll`, `_PulseSpeed` (Float 0), `_PulseAmount` (Range 0-1 = 0),
fog props. `rgb = tex*_Color*vcol*_Intensity*(1+sin(t*_PulseSpeed)*_PulseAmount)`, Blend SrcAlpha One,
ZWrite Off, Cull Off, Queue Transparent. Used for glows, flames, sparkles, light rays, particles.
### `BananaTime/Sky`
Queue Background (1000), ZWrite Off, Cull Off. Gradient from the WORLD view direction
`d = normalize(worldPos - _WorldSpaceCameraPos)`: `_TopColor`, `_HorizonColor`, `_BottomColor`,
`_HorizonSharpness` (Float 3). Sun: `_SunDir`, `_SunGlowColor` (A = strength), `_SunGlowPower` (Float 6),
`_SunDiscColor`, `_SunDiscSize` (Range 0-0.2 = 0.03). Clouds: `_MainTex` (RGBA, sampled with mesh UV
+ `_Scroll`*t), `_CloudColor` (Color; multiplies texture rgb; texture alpha = coverage), `_CloudShadow` (Color).
Final: `sky = gradient + sunGlow + disc; rgb = lerp(sky, cloudRGB, cloudA*_CloudColor.a)`.

  "normalMap": "", "normalStrength": 0.0,
  "emissionMap": "",

  "rim": [1, 0.9, 0.7, 0.0], "rimPower": 3.0,
  "emission": [0, 0, 0], "emissionIntensity": 1.0,
  "scroll": [0, 0], "detailScroll": [0, 0],
  "wind": 0.0, "fog": 1.0,
  "intensity": 1.0,                // Transparent/Additive brightness
  "pulse": [0, 0],                 // Additive [speed, amount]
  "renderQueueOffset": 0,
  "sky": { "top": [0.3,0.55,0.9], "horizon": [0.85,0.92,0.95], "bottom": [0.6,0.75,0.8],

(`sky` must be present in every entry; it is only used when `shader` = "Sky".) Comments above are
documentation only — real JSON files must not contain comments. Validate your JSON with
